App Map & Architecture

Appeal Pilot

Turn confusing health insurance denials into clear, actionable appeal plans in under 60 seconds.

What Appeal Pilot Does

When a user uploads a health insurance denial notice (or chooses a sample case), Appeal Pilot translates cryptic denial jargon into plain English, executes deterministic integer date arithmetic to pin down the exact deadline, and equips the patient with a 3-piece Action Kit: a formal appeal letter, a 4-part phone negotiation script, and an RFC 5545 .ics calendar reminder alarm.

System Architecture Diagram

3-Stop Reference Route

Stop 1: Multimodal Vision & Structured Validation
src/lib/gemini.ts → extractDocumentFacts()

Receives base64 image or single-page PDF data, enforces system prompt injection defenses, calls Gemini Flash with native responseSchema, and parses the extracted facts with Zod.

Stop 2: Zero-Timezone Deterministic Date Engine
src/lib/date-calculator.ts → calculateDeadline()

Takes the extracted letter date and statutory deadline phrase, computing exact calendar dates as discrete integer tuples [YYYY, MM, DD]. Eliminates UTC-to-local timezone rollbacks and calculates accurate reminder alarms (14/3 days or 7/1 days).

Stop 3: Reactive Fact Editing & Token Replacement
src/components/ExplanationCard.tsx & src/components/tabs/AppealLetterTab.tsx

Renders the verified case facts (Insurer, Claim #, Amount, Date). Edits propagate instantly to the appeal letter via tokens ({{INSURER}}, {{CLAIM_NUMBER}}) in local state, requiring zero round-trip AI latency.

To Change This, Start Here

  • Add/Modify Sample Letters: src/lib/sample-data.ts contains golden facts and templates.
  • Modify Calendar Alarm Schedules: src/lib/date-calculator.ts sets reminder days (14/3 for estimated, 7/1 for explicit).
  • Adjust AI Extraction Prompts: src/lib/gemini.ts holds the system instructions and Zod schemas.
  • Update Visual Theme & Colors: src/components/Logo.tsx and tailwind.config.ts control typography and brand tokens.

A Practice to Reuse: Deterministic Logic First, AI for Language

The Problem: Large Language Models are prone to arithmetic errors, calendar hallucinations, and date shifting. Having an AI guess deadlines or calculate days-left introduces subtle, unacceptable mistakes.

The Solution in Appeal Pilot: We strictly decoupled the tasks. The AI is tasked solely with reading literal words and writing empathetic, professional prose. All date math, deadline calculations, calendar formatting, and field edits are handled in deterministic TypeScript code. This ensures 100% mathematical reliability, zero timezone drift, and instant real-time client edits without API latency.

How to Run Locally

Run npm run dev and open http://localhost:3000.
Run unit tests with npm test.
Run live Gemini Vision tests with npm run test:live (requires GEMINI_API_KEY in .env.local).
